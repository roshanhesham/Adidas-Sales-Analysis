# Adidas Sales Analysis

## 📊 Project Overview

This project analyzes Adidas sales data using **Microsoft Power BI** to explore sales performance, profitability, and customer transactions.

The dashboard was created as a practical data analytics project and focuses on transforming raw data into meaningful business insights.

## 🛠️ Tools Used

* Microsoft Power BI
* Power Query
* DAX
* Data Visualization

## 📌 Key Analysis Areas

* Total Sales
* Total Profit
* Profit Margin
* Total Orders
* Average Order Value (AOV)
* Sales by Year
* Sales by Gender
* Sales by Region
* Sales by Category
* Payment Methods

## 📁 Project Files

* **Adidas-Sales-Analysis.pbix** — Power BI dashboard
* **Dashboard_Report.pdf** — PDF version of the dashboard

## 📂 Dataset

The dataset was obtained from **Kaggle** and was used for educational and portfolio purposes.

## 🎯 Project Goal

The goal of this project is to practice data cleaning, data modeling, DAX calculations, KPI development, and dashboard design using Power BI.
